# Pivot seeding CLI

The `repeats` command has been replaced by `seeds-sub` with explicit R and S.
The current CLI, CSV contract, table format, C APIs and migration instructions
are documented in [SEEDING.md](SEEDING.md).

The lower-level repeat-batching C APIs retain their existing semantics.
Historical runtime and collision measurements are in
[REPEATS_OUTWARD.md](REPEATS_OUTWARD.md) and
[REPEATS_RESIDUES.md](REPEATS_RESIDUES.md).
